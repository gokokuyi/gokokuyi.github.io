IT・システム
▶
社内ポータルのパスワードをリセットする手順は以下の通りです。
  1. 社内ポータルのログイン画面で「パスワードを忘れた方はこちら」をクリック
  2. 登録済みの社員番号またはメールアドレスを入力
  3. 社用メールに届いたリセットリンクから新パスワードを設定（有効期限30分）
  4. リセットできない場合は IT ヘルプデスク（内線: 5000）へご連絡ください
📞 IT ヘルプデスク: 内線5000 🕐 対応時間: 平日9:00〜18:00
▶
VPN（GlobalProtect）の接続手順です。
  1. GlobalProtect クライアントを起動（タスクバーのアイコン）
  2. 接続先: vpn.company.co.jp を入力して「接続」
  3. 社員番号とパスワードを入力し、スマホに届いた2段階認証コードを入力
  4. 初回インストールが必要な場合は ITポータル > ソフトウェア配布 からダウンロード
🔧 接続先: vpn.company.co.jp 📱 2段階認証必須
▶
端末申請は IT 機器申請フォームから行います。
  1. 社内ポータル → IT申請 → 「端末・機器申請」を選択
  2. 申請区分（新規/交換/増設）、機種、用途を入力
  3. 部門長の電子承認後、IT部門で調達（通常2〜3週間）
  4. 故障の場合は IT ヘルプデスク（内線5000）へ先に連絡してください
📋 申請フォーム: 社内ポータル > IT申請 📅 調達期間: 2〜3週間

メール容量の上限は1アカウント50GBです。大容量ファイルは以下の方法で送付してください。
  1. 社内ファイル共有（SharePoint/Teams）にアップロードしてリンクを共有

人事・労務
▶
有給休暇の申請は就業管理システム（KING OF TIME）から行います。
  1. KING OF TIME にログイン → 「休暇申請」タブをクリック
  2. 取得日、種別（全日/半日/時間単位）を選択して申請
  3. 直属の上長が承認すると確定（原則2営業日以内に承認）
  4. 年次有給は入社から6か月後に10日付与、以降勤続年数に応じて増加
💻 KING OF TIME で申請 📅 前日までに申請推奨
▶
当社の育児休業制度は育児・介護休業法に基づき、以下の通りです。
  1. 取得対象: 子が1歳に達するまで（保育園未入所等の場合は最長2歳まで延長可）
  2. 産前産後休暇: 産前6週（多胎14週）〜産後8週は取得義務あり
  3. パパ育休: 出生後8週以内に最大4週の育児休業が取得可能（2回まで分割）
  4. 申請方法: 取得予定日の1か月前までに人事部へ申請書を提出
📞 人事部: 内線3000 📄 申請書: 社内ポータル > 人事書類
▶
給与明細は毎月25日に電子明細で配信されます。
  1. 社内ポータル → 「給与・勤怠」→「電子給与明細」をクリック
  2. 当月・過去24か月分の明細を PDF でダウンロード可能
  3. 初回ログイン時は社員番号 + 生年月日（8桁）がパスワード
  4. 内容に疑問がある場合は人事部（内線3000）へご相談ください
📅 配信日: 毎月25日 💻 社内ポータル > 給与・勤怠

経費・精算
▶
経費精算はクラウド経費システム（Concur）で行います。
  1. Concur（concur.company.co.jp）にログイン → 「経費精算」→「新規作成」
  2. 支出日、金額、科目（交通費/接待費等）を入力し、領収書を撮影添付
  3. 上長の電子承認後、翌月給与と合算して振込
  4. 月末締め：毎月20日までの申請分が翌月25日に支払い
💻 Concur: concur.company.co.jp 📅 締め日: 毎月20日
▶
電子帳簿保存法対応により、2024年1月から電子保存に完全移行しました。
  1. 領収書はスキャン or スマホ撮影して Concur に添付（原本不要）
  2. 撮影基準: 金額・日付・発行者が判読できる鮮明な画像（JPEG/PDF）
  3. 紛失した場合は「支払証明書」（Concur 内テンプレート）で代替申請
  4. 1万円以上の接待交際費は参加者名簿の添付が必要
📱 スマホ撮影OK 💡 電子帳簿保存法対応済
▶
出張旅費規程に基づいて精算してください。
  1. 新幹線は原則自由席（乗車時間2時間以上は指定席・グリーン車も可）
  2. 飛行機はエコノミークラス（路線によっては事前にIT旅行サービスで手配）
  3. 日当: 宿泊出張 2,000円/日、日帰り出張 1,000円/日（役職に応じた追加支給あり）
  4. 出張前に「出張申請」を提出し、出張後5営業日以内に精算
📋 旅費規程: 社内ポータル > 規程集 📅 精算期限: 帰社後5営業日

総務・施設
▶
在宅勤務は週3日まで利用可能です（職種により異なる場合があります）。
  1. KING OF TIME → 「勤務区分変更」→「在宅勤務」を当日または前日までに申請
  2. チームの在宅比率ルール（同一チームの50%以上は出社）を遵守
  3. 在宅勤務手当: 月1,500円（通信費補助）が毎月自動で支給
  4. 通信環境・セキュリティ要件: VPN接続必須、公衆Wi-Fi使用不可
📅 週3日まで 💴 在宅手当: 月1,500円
▶
会議室は Outlook / Microsoft 365 の会議室予約機能から予約できます。
  1. Outlook カレンダー → 「新しい会議」→「場所を追加」→ 会議室を検索
  2. または社内ポータル → 「施設予約」から地図で会議室を選択
  3. 設備一覧: プロジェクター全室完備、大会議室はホワイトボード・Web会議対応
  4. 30分前まで予約可能、当日キャンセルは必ず行うこと（連続予約制限あり）
💻 Outlook / 施設予約から予約 ⏰ 当日予約は30分前まで
▶
名刺は社内ポータルのオンライン発注システムから注文します。
  1. 社内ポータル → 「庶務申請」→「名刺発注」を選択
  2. 役職・電話番号・メールアドレスを入力し、プレビューで確認
  3. 部門長承認後、印刷会社へ自動発注（通常5〜7営業日で届く）
  4. 入社時・役職変更時は100枚まで会社負担、追加分は部門予算から
📅 納期: 5〜7営業日 💴 100枚まで会社負担
